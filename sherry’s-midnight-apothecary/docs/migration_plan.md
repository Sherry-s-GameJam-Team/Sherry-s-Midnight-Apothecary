# 旧项目迁移计划

旧仓库在整个迁移期保持只读，只作为美术与功能参考。

1. 优先盘点并迁移原始美术、音频及其授权信息，不复制旧架构耦合。
2. 建立稳定 ID 与对应 Definition，再导入资源，避免用路径充当业务身份。
3. 不直接迁移旧 `GameRoot`，改由本仓库的 `AppRoot`、`GameFlow` 与 `SceneFlow` 组合。
4. 不直接迁移完整旧关卡 `.tscn`；拆出纯视觉与纯玩法内容。
5. 不迁移旧关卡内的玩家、主摄像机或正式 HUD；由新的 `DayLevelRuntime` 创建。
6. 以森林作为第一张垂直切片关卡，贯通探索、采集、结果、夜间商店与存档交接。
7. 垂直切片验证后再迁移集市。
8. 湖泊最后迁移，利用前两张关卡稳定后的契约与工具。

迁移过程中不提前实现完整 30 天内容，也不一次性搬入集市、森林和湖泊的完整场景。
