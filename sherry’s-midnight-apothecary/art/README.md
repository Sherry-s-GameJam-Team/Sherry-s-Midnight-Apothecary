# 美术资源目录

工程图片、动画帧及其美术资源描述文件统一存放在此目录，并按场景或复用范围分类。

```text
art/
├── doorchanger/             # 地图与场景切换界面
├── lake/                    # 湖泊场景、波纹蒙版
├── raintree/                # 雨树场景、启动动画
├── title_menu/              # 标题菜单与字形
├── town/                    # 城镇背景、道具和特效
└── shared/
    ├── characters/          # 跨场景角色与动画
    ├── environment/         # 跨场景植被
    ├── interactions/        # 睡眠等交互动画
    └── ui/                  # 项目图标等共享界面资源
```

新增图片时应优先放入对应场景目录；多个场景共同使用的资源放入 `shared`。不要把脚本或普通关卡场景迁入此目录，只有与动画帧紧密绑定的 `SpriteFrames`、清单及小型美术组件场景可与素材放在一起。
