# 血叶猎王·阿尔凯昂 (Alkeon Boss Encounter)

## 概述
`res://day/levels/Crimson Vale/boss/alkeon_arena.tscn` 是赤染溪谷的 Boss 决战关卡场景。
- **战场名称**: 赤角古道·丹心门前
- **Boss 名称**: 血叶猎王·阿尔凯昂 (Alkeon, King of the Blood Leaf Hunt)
- **Boss 贴图**: `res://day/levels/Crimson Vale/purified_deer_spirit_transformation_spritesheet.png` (24帧渐变演化序列) 与 `purified_deer_spirit.png` (净化圣鹿)

## 战场架构与视觉布局（三版面无缝连贯）

战场总跨度约 1700px，分为三个自然连贯的版面，无硬实体墙隔断：
- **左区 (L)**: $X \in [0, 550]$，悬挂 `BellLeft`，枫树与碎石柱边界。
- **中区 (C)**: $X \in [550, 1150]$，悬挂 `BellCenter`，Boss鹿头位于中后景浮动，后方立有丹心界门。
- **右区 (R)**: $X \in [1150, 1700]$，悬挂 `BellRight`，古驿道地砖与枫树边界。

## 核心机制

### 1. 风铃预警系统 (Wind Chime Telegraph)
- **声响节奏**:
  - 第一响（`当——`，音调区分 L:440Hz / C:523Hz / R:659Hz）：选中目标危险区域。
  - 0.8秒后：红叶逆风飘聚，地面浮现淡红流向指示箭头。
  - 0.7秒后（`当、当。` 双响）：血叶潮正式冲入版面。
- **物理互动**:
  - 用【爆炸药水】命中正在响动的风铃，可使该版面本次血叶潮延迟约 1.0 秒。

### 2. 血叶潮类型 (Blood Leaf Surge)
- **横扫潮 (Horizontal Sweep)**: 沿地面与空中水平横穿版面。
- **下压潮 (Downward Crush)**: 从树冠自上而下砸落，下层掩体安全。
- **聚拢潮 (Converging Swarm)**: 自左右两侧同时向版面中心压缩。

### 3. 御风药水主动破局 (Headwind Safe Zone)
- 玩家向危险版面投掷【御风药水】，可短暂制造持续 1.8~2.0 秒的**逆风安全区**，强风反卷血叶，将危险区逆转为安全避难点。

## 战斗三阶段流程

### 第一阶段：「赤角巡猎」(HP 100% → 67%)
- **Boss 形态**: 第一形态（神圣鹿角与淡淡血痕）。
- **攻击模式**: 抽袋随机（Bag Randomization，轮流打完 L/C/R）单区血叶潮，间歇在安全区生成 `BloodLeafSwarm` 逼迫走位。
- **弱点输出**: Boss 低头（持续 3.5 秒）→ 爆炸药水击碎面部叶甲 → 净化药水命中核心造成约 12% 进度伤害。

### 第二阶段：「狂猎再临」(HP 67% → 34%)
- **转阶段演出**: 4 秒变身动画，血泪蔓延，神性光芒减弱，全场三铃齐鸣。
- **攻击模式**: 同时封锁双区（留下唯一安全区），交错波次攻击，生成双延迟追踪叶群（`tracking_delay` 0.45s 与 0.85s）。
- **弱点输出**: Boss 低头 3.0 秒 → 爆炸药水破盾 → 净化药水重创。

### 第三阶段：「万叶大猎」(HP 34% → 0%)
- **转阶段演出**: 黑红藤蔓蔓延，鹿角睁开多重眼眸，红叶逆流升腾。
- **攻击模式**: Pattern 模式连续变幻（A/B/C/D 组合），引入**虚假风铃**机制（鹿角假铃声，需肉眼观察版面物理风铃真身）。
- **终极技能 —「万叶归猎」(HP ≤ 10%)**:
  - 全场三铃异步长鸣，三大版面全域血叶覆盖（全场无自然安全区）。
  - 玩家必须使用【御风药水】强行开辟逆风区坚持 3 秒。
- **终极三步净化流程**:
  1. 投掷【爆炸药水】击碎外层血叶铠甲；
  2. 投掷【御风药水】锁定逆风，阻止血叶回流；
  3. 投掷【净化药水】精准命中灾核！

## 通关与奥雷姆钟庭衔接

- 净化完成瞬间，全场风铃静止，血叶定格 0.5 秒化为柔和枫叶飘落，Boss 恢复圣鹿形态行礼。
- 后方丹心门三重风铃依次敲响，声音融合成宏大钟庭钟鸣，界门由红金色转化为橙金色齿轮纹样，伴随机械钟摆滴答声，开启前往【奥雷姆钟庭 (`orem_clocktower`)】的传送门。
