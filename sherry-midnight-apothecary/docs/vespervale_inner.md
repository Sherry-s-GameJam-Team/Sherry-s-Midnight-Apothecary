# 梦疗院·病栋回廊 (Vespervale Inner Ward Corridor) 关卡

## 概述
梦疗院·病栋回廊 (`res://day/levels/Vespervale/inner.tscn`) 是暮息谷（Vespervale）的内部核心双角色协作平台关卡。
关卡采用 2D 横板长走廊单画幅结构（全长约 5100px），上下两层并行，强调 **“按 C 键双角色切换 (雪莉/卢卡) + 虚实节拍切换 (梦境常态/现实入侵)”** 的高难策略平台挑战。

---

## 核心机制：双角色分工与虚实节拍 (Dual-Character & Rhythm)

### 1. 角色分化与定位
- **雪莉 (Sherry - 下层主推进者)**：
  - 走下层主通道，处理地面障碍、投掷药水打亮远端目标 (`LightTarget`)。
  - 终点激活梦髓节点 (`DreamMarrowNode`)。
  - **最佳节奏**：现实入侵窗口下高速冲刺，梦境态寻找掩体躲避密集弹幕。
- **卢卡 (Luca - 上层机关开路者)**：
  - 走上层狭窄观察廊，操作治疗记录板、医药柜机关 (`InteractiveSwitch`)。
  - 打开雪莉前方的门帘、铁栅门并抑制下层弹幕；接受雪莉的远程药水掩护。
  - **最佳节奏**：梦境态下推进，依赖梦桥与梦床跳台开路。

### 2. 状态节拍与节拍器切换
- **梦境态 (Dream State - 主常态，约 7～11 秒)**：
  - 推荐切 **卢卡** 在上层推进（梦桥/梦床凝聚显现，可跨越断桥）。
  - 下层弹幕发射口、天花板紫铃藤激活，对雪莉较危险。
- **现实入侵 (Reality Intrusion - 短暂态，约 2.5～4.0 秒)**：
  - 推荐切 **雪莉** 在下层快跑冲刺（所有弹幕完全停火，地面病床消失全通畅）。
  - 上层梦桥/梦床消散，担架在地面开始物理巡逻。
- **操作节拍**：
  - **梦境来 → 切卢卡上层推进；现实来 → 切雪莉下层冲刺**，形成自然的闯关节拍器。

### 3. 控制与判定公平规则
- **C 键切换**：按 `C`（或 `Tab`）在雪莉 / 卢卡之间即时切换操控，UI 与角色轮廓高亮提示当前活动角色。
- **非操控角色受击保护**：
  - 非操控角色**不受弹幕伤害**，避免流弹偷袭的挫败感。
  - 非操控角色**仍受物理存在性影响**（如站在梦桥/梦床上，现实入侵来时由于桥床消散仍会掉落），要求玩家将另一人停留在稳定实体地形后再切人。

## 六大关卡区段 (Zone 0 ～ Zone 5)

### Zone 0：入口前厅 (x: 0 ~ 600)
- **教学目的**：C 键切人、梦境/现实节奏、上下层分工教学。
- **流程**：雪莉下层进场被门帘 `CurtainGate_A` 阻挡；梦境来临后上层显现梦床跳台，切卢卡登上上层操作记录板 `Broad1` 打开门帘；现实入侵来临，切雪莉穿过停火的高窗。

### Zone 1：双病房廊 (x: 600 ~ 1450)
- **教学目的**：正式建立“上下互开安全窗口”。
- **流程**：
  - 梦境态切卢卡躲避紫铃藤落刺，操作 `ControlBroad_A` 开启铁栅门并关闭下层 1 号窗户发射器。
  - 现实入侵切雪莉沿平坦走廊快跑，投掷药水击中 `LightTarget_A`。
  - 该灯点亮后使卢卡前方 2 号紫铃藤短暂停摆，切卢卡安全通过上层尾段。

### Zone 2：担架巡逻廊 (x: 1450 ~ 2350)
- **教学目的**：引入“现实态地面物理碰撞、梦境态地面对空弹幕”的双重压力。
- **流程**：
  - 梦境态切卢卡踏过梦桥操作 `CabinetSwitch_A`，降低下层担架移速并解锁门禁。
  - 现实入侵切雪莉在巡逻担架间隙穿梭，梦境恢复后借沙发掩体躲避上射光弹。
  - 雪莉在末端投掷药水打中 `LightTarget_B`，使上层扇形发射器停火 4 秒，切卢卡冲过上层。

### Zone 3：观察连桥区 (x: 2350 ~ 3250)
- **教学目的**：严谨的切换节奏考量，不允许拖延。
- **流程**：
  - 梦境态切卢卡连续通过两段梦桥到达 `BroadSwitch_B`，打开下层 `CurtainGate_B`。
  - 现实入侵切雪莉在三个病房门完全停火的短窗口内冲刺穿过长廊，打中 `LightTarget_C` 使上方紫铃藤失效，卢卡跟进。

### Zone 4：沉眠病栋核心 (x: 3250 ~ 4200)
- **教学目的**：全关机制综合高压挑战。
- **流程**：
  - 梦境态切卢卡连躲 3 串紫铃藤垂刺并过桥操作 `WardControl_A`，关闭一侧交叉发射器留出通行缝隙。
  - 现实入侵切雪莉利用空档穿过担架，梦境态跳上病床躲避交叉火力，投掷药水击中 `LightTarget_D` 打开上层铁栅门，卢卡通过。

### Zone 5：梦髓节点室 (x: 4200 ~ 5100)
- **教学目的**：终点高潮解谜与双人合流撤离。
- **流程**：
  - 现实入侵切卢卡在上层先后操作 `BroadSwitch_C1` 与 `C2` 控制板，大幅减弱下一次梦境态中的交叉发射阵列。
  - 梦境态来临铁栏消散，切雪莉冲入中央按 `E` 激活 `DreamMarrowNode` 净化病栋。
  - 节点激活后 `WardExitDoor` 升起，上层降下斜坡让卢卡下到底层，双人合流抵达 `ExitPortal` 通关。

## 机制组件清单 (`inner_systems/`)

- `inner_party_controller.gd`：双角色切换控制器（按 C/Tab 切换、相机挂载、输入分流、受击保护、状态高亮）。
- `inner_party_switch_ui.gd`：屏幕左上角双角色状态与节拍提示 HUD。
- `interactive_switch.gd`：记录板、柜门、控制台交互开关（开门、临时停火发射器、减速机关）。
- `light_target.gd`：药水打击感应吊灯（受击点亮，临时击晕上层危险藤蔓或发射器）。
- `curtain_gate.gd`：可开启升降门帘。
- `iron_grate_door.gd`：可开启升降铁栅门。
- `dream_shift_manager.gd`：梦境态 (7～11s) ⇄ 现实入侵 (2.5～4s) 状态机。
- `dream_bullet.gd`：梦境光弹（对非操控角色免疫，立柱掩体可吸收）。
- `ward_bullet_launcher.gd`：支持临时停火与 0.4s 预警亮灯的弹幕发射器。
- `vine_falling_thorn.gd`：支持药水击晕与 0.5s 剧烈摇晃预警的坠刺紫铃藤。
- `dream_bridge.gd`：梦境显现实体桥板，现实消散。
- `dream_thorn_bed.gd`：梦境显现原色跳台，现实消散。
- `rolling_stretcher.gd`：现实巡逻碰撞、梦境驻留对空射击担架车。
- `dream_marrow_node.gd` & `ward_exit_door.gd`：梦髓终点机关与出口大门。
