# NPC frontal bust prompt set

All 18 assets were generated with the built-in image generation tool, using each folder's `source_cutout.png` as its character reference.

## Shared prompt

Use case: stylized-concept. Asset type: 2D side-scroller game NPC character bust asset. Create the same referenced character as a centered, symmetrical waist-up portrait in a strict frontal view and pure 2D orthographic projection. Preserve identity, age, costume colors, and signature profession props. Use 2D hand-drawn illustration, clean dark ink outlines, flat colors, a warm and cozy muted medieval palette, soft ambient lighting, and highly detailed line art consistent with the reference. Keep shoulders level, the face looking directly at camera, all visible faces parallel to the screen, and perfect horizontal and vertical alignment. Render on a perfectly flat solid `#ff00ff` chroma-key background with no floor, shadow, gradient, texture, reflection, text, or watermark.

Avoid: 3D, isometric, perspective, depth of field, top-down view, side or profile view, three-quarter view, turned head, vanishing points, foreshortening, visible top or side faces, tilted or angled composition, dimension, volume, realistic shading, shadows casting depth, architectural rendering perspective, extra characters, and cropped heads or shoulders.
