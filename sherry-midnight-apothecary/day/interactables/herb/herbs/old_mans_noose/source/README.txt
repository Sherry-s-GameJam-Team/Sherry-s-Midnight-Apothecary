Old Man's Noose / 绞索老汉

The painted master was reconstructed from the supplied 6.png reference with
the imagegen workflow. It preserves the diagonal host branch, yellow-green
crustose lichen, hanging ribbon-like thalli, and rope-loop terminals.

Processing layout:
- 1 host branch piece: detachable waste, not grindable
- 11 left-to-right hanging thallus pieces: detachable and grindable
- 4096 x 4096 reference canvas
- 256 x 256 inventory thumbnail and badge

Regenerate the derived master, thumbnails, split pieces, and manifest with:
    python tools/build_old_mans_noose_assets.py
